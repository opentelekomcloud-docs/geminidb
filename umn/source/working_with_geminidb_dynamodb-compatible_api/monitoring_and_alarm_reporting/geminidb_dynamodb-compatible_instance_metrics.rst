GeminiDB DynamoDB-Compatible Instance Metrics
=============================================

Description
-----------

This section describes GeminiDB DynamoDB-Compatible instance metrics reported to Cloud Eye as well as their namespaces and dimensions. You can query instance metrics and alarms through the APIs provided by Cloud Eye.
